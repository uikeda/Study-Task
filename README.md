# Study-Task

勉強タスクの **量・期限・進捗** から、毎日やるべき量（ノルマ）を自動で計算する学習管理Webアプリです。
ビルド不要の静的サイト（HTML / CSS / JavaScript）で、データはブラウザの localStorage に保存されます。

## 使い方

`index.html` をブラウザで開くだけで動きます（GitHub Pages などの静的ホスティングにもそのまま置けます）。

1. 「タスク」タブで、タスク名・全体量・単位（ページ／問／語など）・開始日・期限・学習する曜日を登録
2. 「今日」タブに今日のノルマが表示されるので、やった量を入力（「ノルマ分を記録」で一発入力も可）
   - 時間割を登録していれば、上部に「今の時間にやるタスク」と次のタスクが表示されます（下記）
3. 「カレンダー」タブで日付をクリックすると、その日のタスクを確認できます
   - 過去の日: 実際にやった量 / 今日: ノルマと実績 / 未来の日: 計画どおり進めた場合の予定量
   - 「＋ この日に試験・模試を追加」で、試験（本番）・模試・その他の予定を書き込めます
   - 近い予定は「今日」とカレンダーの上部にカウントダウン表示されます（一番近い「本番」を大きく表示）
4. 「週間」タブで、これから7日間の予定量を確認
5. 「達成度」タブで、日ごとのノルマ達成率とタスク別の進み具合をグラフで確認（下記）
6. 終わったタスクの復習は「復習」タグを付けたタスクとして管理します（下記）
7. 「連携」タブで、Claude に直接相談するか、チャットとテキストで計画をやり取り（下記）

## 時間割

- 「時間割」タブの「＋ 時間を追加」で、開始・終了時刻とやるタスク（またはタスク以外の内容）を登録します。
  「毎週」なら選んだ曜日に毎回、「この日だけ」ならその日だけ表示されます。
- 「今日」タブの上部に、今の時間のコマ（残り時間と、そのタスクの今日のノルマの残り）と次のコマを表示し、
  今やるタスクのカードを枠で強調します。表示は30秒ごとに更新されます。
- 時間が重なるコマは保存前に確認し、一覧にも「重なっています」と表示します。日付をまたぐコマは2つに分けてください。
- タスクを削除しても時間割のコマは残ります（タスク名が内容として引き継がれます）。

## 達成度

- **日ごとのノルマ達成率**（直近14日）: その日にノルマがあったタスクごとの達成率（100%が上限）の平均です。
  単位の違うタスク（ページと語など）の量を足し合わせないよう、タスク単位で平均しています。
  過去の日のノルマは、その日までの記録で計算し直した値です（タスクの期限や量を後から変えると過去の値も変わります）。
  タスクを登録した日より前の日は、そのタスクを評価に含めません。
- **連続達成**: すべてのノルマを達成した日が何日続いているか。ノルマのない日は飛ばし、今日が途中なら昨日までを数えます。
- **タスク別の進み具合**: 終えた割合の棒と、当初の計画どおりなら今日までに終えているはずの割合（縦線）を並べて表示します。
- グラフにはマウスやキーボードのフォーカスで値が出ます。「表で見る」で同じ値を表で確認できます。

## AI に直接相談する（Claude API）

「連携」タブの「AI に直接相談する」から、アプリ内で Claude にプロンプトを送れます。

- 「API の設定」に [Anthropic Console](https://console.anthropic.com/) で発行した API キーを入力します（利用料は API キーの持ち主に請求されます）。
  モデルは Claude Opus 5.5（既定）・Sonnet 5.5・Haiku 5.5 から選べます。
- 送信時には、計画づくりの書式（[prompts/plan-prompt.md](prompts/plan-prompt.md) と同じ内容）と現在の計画が一緒に送られるので、
  「数学を週3日に減らして」「英単語を100語進めた」のように頼めます。情報が足りなければ AI が質問してきます。
- 返信に計画が含まれていると「この計画を取り込む（内容を確認）」ボタンが出ます。押すと下の「2. チャット → アプリ」に入り、
  追加・変更・削除の確認を経てから反映されます（AI の返信がそのまま反映されることはありません）。
- 会話はページを開いている間だけ保持されます。
- API キーはブラウザから Anthropic に直接送ります（他のサーバーは経由しません）。「このブラウザに保存する」を選んだ場合だけ
  localStorage に保存され、学習データのバックアップ（JSON）には含まれません。共用のパソコンでは保存しないでください。
- Claude の SDK（`@anthropic-ai/sdk`）は送信時に CDN（jsDelivr）から読み込みます。

## 復習の管理

- 終わったタスクのカードにある「＋ 復習タスクを作る」で、名前（「○○ 復習1回目」）・量・単位を引き継いだ
  復習タスクを作れます。タスクの追加・編集画面の「復習タスクにする」でも付け外しできます。
- 復習タスクは通常のタスクと同じく、期限と学習日から毎日のノルマを計算します。
- 終わったタスクのカードには、復習の回数・各回の進み具合・前回の復習（未復習なら完了）からの経過日数を表示します。
- タスク一覧の「復習」フィルタで、復習タスクと終わったタスクだけを表示できます。
- 元のタスクを削除しても、復習タスクと記録は残ります（ひも付けだけ外れます）。

## チャットとの連携（テキスト）

アプリとチャットは直接つながらないため、テキストのコピー＆ペーストかファイルでやり取りします。

- **計画を新しく作る**: 「プロンプトをコピー」で、今日の日付と出力形式を指定したプロンプトをコピーし、
  新しいチャットに貼り付けて目標・教材・使える時間を書き足します（本文は [prompts/plan-prompt.md](prompts/plan-prompt.md)）。
  返信を丸ごと貼り付けても、コードブロックがあればその中だけを読み込みます。

- **アプリ → チャット**: 「テキストをコピー」（または .md で保存）してチャットに貼り付け、
  「この計画を見直して、同じ書式で返して」などと頼みます。書式の説明がテキストに含まれています。
- **チャット → アプリ**: 返ってきたテキストを貼り付け（またはファイルを開き）、「内容を確認」で
  追加・変更・削除されるタスクを確認してから反映します。

書式（1タスク分）:

```md
## 青チャート数IA
- id: （アプリが付ける。新しいタスクでは書かない）
- 科目: 数学
- 量: 240 問
- 済: 20
- 開始: 2026-10-22
- 期限: 2026-11-15
- 曜日: 月火水木金土   （「毎日」「平日」「土日」も可）
```

- id のないタスクは新規追加、テキストから消えたタスクは削除になります。
- 「済」が増えた分は今日の実績として記録し、減った分は補正値として差し引きます。
- 「状況」行は参考情報で、読み込み時は無視します。
- 復習タスクは「- タグ: 復習」「- 復習元: 元のタスク名」で表します。
- 試験・模試の予定と時間割はテキスト連携の対象外です（読み込んでも消えません）。

## ノルマの計算方法

- **今日のノルマ** = 今日開始時点の残量 ÷ 今日から期限までの学習日数（端数は早い日に多く配分）
- 今日記録しても今日のノルマ自体は変わりません。多く進めた分は翌日以降のノルマが減り、
  サボった分は翌日以降のノルマに上乗せされます。
- **状態の判定**: 現在必要な1日あたりペースを、計画当初のペースと比べます。
  - 1.2倍超 → 遅れ / 0.9倍未満 → 先行 / それ以外 → 順調
  - 期限を過ぎて残っている → 期限切れ、期限までに学習日が残っていない → 遅れ（残り全量が今日のノルマ）

## データ

- ブラウザごとに保存されます（端末間の同期はありません）。
- 「タスク」タブ下部の「データのバックアップ」から JSON で書き出し・読み込みができます。

## 開発

```sh
npm test   # 計算ロジックのユニットテスト
```

- `js/planner.js` … ノルマ・状態・達成度の計算（DOM 非依存の純粋関数）
- `js/schedule.js` … 時間割の計算（DOM 非依存の純粋関数）
- `js/textformat.js` … チャット連携用テキストの書き出し・読み込み
- `js/ai.js` … Claude API へのリクエストの組み立てと送信
- `js/app.js` … 画面描画と保存処理
