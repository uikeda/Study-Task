# Study-Task

勉強タスクの **量・期限・進捗** から、毎日やるべき量（ノルマ）を自動で計算する学習管理Webアプリです。
ビルド不要の静的サイト（HTML / CSS / JavaScript）で、データはブラウザの localStorage に保存されます。

## 使い方

`index.html` をブラウザで開くだけで動きます（GitHub Pages などの静的ホスティングにもそのまま置けます）。

1. 「タスク」タブで、タスク名・全体量・単位（ページ／問／語など）・開始日・期限・学習する曜日を登録
2. 「今日」タブに今日のノルマが表示されるので、やった量を記録（下記「今日タブ」）
3. 「カレンダー」タブで日付をクリックすると、その日のタスクを確認できます
   - 過去の日: 実際にやった量 / 今日: ノルマと実績 / 未来の日: 計画どおり進めた場合の予定量
   - 過去の日は「記録を直す」で、やった量をあとから入れたり直したりできます（下記）
   - 「＋ この日に試験・模試を追加」で、試験（本番）・模試・その他の予定を書き込めます
   - 近い予定は「今日」とカレンダーの上部にカウントダウン表示されます（一番近い「本番」を大きく表示）
4. 「週間」タブで、これから7日間の予定量を確認
5. 「達成度」タブで、日ごとのノルマ達成率とタスク別の進み具合をグラフで確認（下記）
6. 終わったタスクの復習は「復習」タグを付けたタスクとして管理します（下記）
7. 「連携」タブで、Claude などのチャットとテキストで計画をやり取り（下記。API キーや利用料は不要）

## 今日タブ

- 時間割に沿って「今やること → このあと → 残っているノルマ → 終わった」の順に並べます。
  今のコマのタスクは黒い枠で強調し、残り時間を表示します。タスク以外のコマ（学校の課題など）も時間の流れに入ります。
  時間割に入っていないタスクや、コマが終わってもノルマが残っているタスクは「残っているノルマ」に出ます。
- 記録はボタンで増減できます（−1 / +1 / +5、ノルマが30以上のタスクは +10 / ノルマ分）。数字の欄に直接入力もできます。
- 遅れているタスクには「遅れを立て直す」が出ます（下記）。
- 表示は30秒ごとに更新します（入力中は更新しません）。

## 記録のつけ忘れ

- 直近7日のうち、ノルマがあったのに記録が一つもない日があると、「今日」タブに知らせます。
  「入力する」でその日の記録画面を開き、「勉強しなかった」を選ぶとその日は知らせなくなります。
- カレンダーでは、その日を「未記録」と表示します。押すとそのまま記録を入れられます。
- 過去の日の記録を直すと、今日以降のノルマを計算し直します。保存前に、今日のノルマがどう変わるかを表示します。
  （タスクを登録した日より前の日は、記録がない限り対象にしません）

## 遅れの立て直し

「タスク」タブや「今日」タブの遅れているタスク（状態が「遅れ」「期限切れ」）から「遅れを立て直す」を開くと、
今の状況と立て直し方の候補を、それぞれの1日あたりの量と一緒に表示します。選んで「この内容で変更」で反映します。

- 状況: 残りの量、期限に間に合わせるのに必要なペース、最近7学習日の実際のペース、そのペースで終わる日
- 候補: 最近のペースに合わせる（期限を、最近のペースで終わる日にする）／ 期限を1週間延ばす ／ 毎日を学習日にする ／
  全体量を減らす（最近のペースのままで期限までに終わる量まで）／ このまま続ける
- どれも合わないときは「AI に相談する」で、状況を「連携」タブの相談欄に入れてチャットに相談できます。

## 時間割

- 「時間割」タブの「＋ 時間を追加」で、開始・終了時刻とやるタスク（またはタスク以外の内容）を登録します。
  「毎週」なら選んだ曜日に毎回、「この日だけ」ならその日だけ表示されます。
- 「今日」タブは時間割に沿ってタスクを並べます（上記）。
- 「時間割」タブは1日のタイムラインで表示します。コマの高さは時間の長さに比例し、コマの間の空き時間と、今日なら今の時刻の線を表示します。
  2時間以上コマのない時間帯は「空き ○時間○分」の1行にたたみます。コマを押すと編集できます。
- コマはタスクの科目ごとに色分けします。色は4色で、科目が出てきた順に割り当て、一度決まった色は変わりません
  （その科目のタスクがなくなると色が空き、新しい科目に使われます）。5科目目以降、科目のないタスク、タスク以外のコマは灰色（その他）です。
  色だけに頼らないよう、科目名はいつも文字で表示します。
- 時間が重なるコマは保存前に確認し、タイムラインでは横に並べて表示します。日付をまたぐコマは2つに分けてください。
- タスクを削除しても時間割のコマは残ります（タスク名が内容として引き継がれます）。

## 達成度

- **完了の見通し**: 最近7学習日の実際のペースで進めた場合に、各タスクが終わる日と、期限からの遅れ（早さ）を表示します。
  「遅れ」の判定（必要なペースと当初のペースの比較）とは違い、実際の進み方から見た見通しです。
  タスクを選ぶと、累計の実績・当初の計画・このペースの見込みをグラフで表示します。記録が5学習日分より少ないと参考値です。

- **日ごとのノルマ達成率**（直近14日）: その日にノルマがあったタスクごとの達成率（100%が上限）の平均です。
  単位の違うタスク（ページと語など）の量を足し合わせないよう、タスク単位で平均しています。
  過去の日のノルマは、その日までの記録で計算し直した値です（タスクの期限や量を後から変えると過去の値も変わります）。
  タスクを登録した日より前の日は、そのタスクを評価に含めません。
- **連続達成**: すべてのノルマを達成した日が何日続いているか。ノルマのない日は飛ばし、今日が途中なら昨日までを数えます。
- **タスク別の進み具合**: 終えた割合の棒と、当初の計画どおりなら今日までに終えているはずの割合（縦線）を並べて表示します。
- グラフにはマウスやキーボードのフォーカスで値が出ます。「表で見る」で同じ値を表で確認できます。

## チャットとの連携（テキスト）

アプリとチャットは直接つながらないため、テキストのコピー＆ペーストかファイルでやり取りします。
API は使わないので、Claude・ChatGPT・Gemini などの無料プランで使えます（各サービスの利用回数の制限には従います）。

- **AI に相談する**（新しく計画を作る・見直す）: 相談したいことを入力して「プロンプトをコピー」、または
  「コピーして Claude を開く」などのボタンでチャットを開き、貼り付けて送ります。
  プロンプトには今日の日付・出力形式・今の計画（id 付き）・相談内容が入ります（書式部分の本文は [prompts/plan-prompt.md](prompts/plan-prompt.md)）。
  情報が足りなければ AI が質問してくるので、チャットでやり取りを続けてください。
- 返ってきた計画は「2. チャット → アプリ」に貼り付けます（「クリップボードから貼り付け」も使えます。
  ブラウザによってはクリップボードの読み取りを許可するか、手で貼り付けてください）。
  返信を丸ごと貼り付けても、コードブロックがあればその中だけを読み込みます。
- 無料プランのモデルは書式を守らないことがあります。読み込めない行は行番号付きで表示されるので、直すかチャットに直してもらってください。

- **アプリ → チャット**: 「テキストをコピー」（または .md で保存）してチャットに貼り付け、
  「この計画を見直して、同じ書式で返して」などと頼みます。書式の説明がテキストに含まれています。
- **チャット → アプリ**: 返ってきたテキストを貼り付け（またはファイルを開き）、「内容を確認」で
  追加・変更・削除されるタスクを確認してから反映します。

書式（1タスク分）:

```md
## 青チャート数IA
- id: （アプリが付ける。新しいタスクでは書かない）
- 科目: 数学
- 量: 240 問
- 済: 20
- 開始: 2026-10-22
- 期限: 2026-11-15
- 曜日: 月火水木金土   （「毎日」「平日」「土日」も可）
```

- id のないタスクは新規追加、テキストから消えたタスクは削除になります。
- 「済」が増えた分は今日の実績として記録し、減った分は補正値として差し引きます。
- 「状況」行は参考情報で、読み込み時は無視します。
- 復習タスクは「- タグ: 復習」「- 復習元: 元のタスク名」で表します。
- 試験・模試の予定と時間割はテキスト連携の対象外です（読み込んでも消えません）。

## ノルマの計算方法

- **今日のノルマ** = 今日開始時点の残量 ÷ 今日から期限までの学習日数（端数は早い日に多く配分）
- 今日記録しても今日のノルマ自体は変わりません。多く進めた分は翌日以降のノルマが減り、
  サボった分は翌日以降のノルマに上乗せされます。
- **状態の判定**: 現在必要な1日あたりペースを、計画当初のペースと比べます。
  - 1.2倍超 → 遅れ / 0.9倍未満 → 先行 / それ以外 → 順調
  - 期限を過ぎて残っている → 期限切れ、期限までに学習日が残っていない → 遅れ（残り全量が今日のノルマ）

## データ

- ブラウザごとに保存されます（端末間の同期はありません）。
- 「タスク」タブ下部の「データのバックアップ」から JSON で書き出し・読み込みができます。

## 開発

```sh
npm test   # 計算ロジックのユニットテスト
```

- `js/planner.js` … ノルマ・状態・達成度の計算（DOM 非依存の純粋関数）
- `js/schedule.js` … 時間割の計算（DOM 非依存の純粋関数）
- `js/textformat.js` … チャット連携用テキストの書き出し・読み込み
- `js/app.js` … 画面描画と保存処理
