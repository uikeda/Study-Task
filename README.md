# Study Task

勉強タスクの「総量・期限・進捗」から、毎日のノルマを自動で計算する Web アプリです。
ビルド不要の静的サイト（HTML/CSS/JS）で、データはブラウザの localStorage に保存されます。

## 使い方

`index.html` をブラウザで開くだけで動きます（GitHub Pages などにそのまま置くこともできます）。

1. 「タスク」タブでタスクを追加（例: 問題集 200問、期限 11/30）
2. 「今日」タブに今日のノルマが表示されるので、実績を入力
3. 「計画」タブで今後7日間の見込みと過去14日の達成状況を確認

## ノルマの計算方法

- **今日のノルマ** = ⌈ その日の開始時点の残量 ÷ 今日〜期限の学習日数 ⌉
  - 当日に記録してもノルマ自体は変わらず、達成度だけが変わります
  - 未達分・先行分は翌日以降のノルマに自動で再配分されます
- **休息日**（設定タブ）の曜日にはノルマを割り当てません。ただし期限日は例外です
- **期限超過**のタスクは残量すべてがノルマになります
- **ペース判定**: 開始日〜期限を均等割りした理想ペースと前日までの実績を比較し、
  1日分の半分以上ずれていれば「遅れ」「先行」と表示します
- 「今日」タブは 期限超過 → 遅れ → 期限が近い 順に並びます

## 開発

```sh
node --test tests/*.test.js
```

計算ロジックは `planner.js`（DOM 非依存）、画面は `app.js` にあります。
