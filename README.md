# Study-Task

勉強タスクの **量・期限・進捗** から、毎日やるべき量（ノルマ）を自動で計算する学習管理Webアプリです。
ビルド不要の静的サイト（HTML / CSS / JavaScript）で、データはブラウザの localStorage に保存されます。

## 使い方

`index.html` をブラウザで開くだけで動きます（GitHub Pages などの静的ホスティングにもそのまま置けます）。

1. 「タスク」タブで、タスク名・全体量・単位（ページ／問／語など）・開始日・期限・学習する曜日を登録
2. 「今日」タブに今日のノルマが表示されるので、やった量を入力（「ノルマ分を記録」で一発入力も可）
3. 「週間予定」タブで、これから7日間の予定量を確認

## ノルマの計算方法

- **今日のノルマ** = 今日開始時点の残量 ÷ 今日から期限までの学習日数（端数は早い日に多く配分）
- 今日記録しても今日のノルマ自体は変わりません。多く進めた分は翌日以降のノルマが減り、
  サボった分は翌日以降のノルマに上乗せされます。
- **状態の判定**: 現在必要な1日あたりペースを、計画当初のペースと比べます。
  - 1.2倍超 → 遅れ / 0.9倍未満 → 先行 / それ以外 → 順調
  - 期限を過ぎて残っている → 期限切れ、期限までに学習日が残っていない → 遅れ（残り全量が今日のノルマ）

## データ

- ブラウザごとに保存されます（端末間の同期はありません）。
- 「タスク」タブ下部の「データのバックアップ」から JSON で書き出し・読み込みができます。

## 開発

```sh
npm test   # 計算ロジック（js/planner.js）のユニットテスト
```

- `js/planner.js` … ノルマ・状態計算（DOM 非依存の純粋関数）
- `js/app.js` … 画面描画と保存処理
